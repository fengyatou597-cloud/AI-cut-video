# AI 视频粗剪助手

一个本地运行的 AI 视频粗剪原型，面向 5-10 分钟中长视频。它可以根据文稿、字幕、旁白录音和素材生成分镜表、粗剪 timeline，并尝试生成可在剪映中继续调整的草稿。

这个工具的定位是“粗剪助理”，不是一键自动成片工具。它不会自动点击剪映，也不会自动导出最终视频。

## 核心功能

- 创建视频项目，设置平台、目标时长、视频风格和剪辑节奏。
- 上传文稿，支持 `.txt`、`.md`、`.docx`。
- 上传 `.srt` 字幕，生成 timeline 时优先使用字幕时间轴。
- 上传视频、图片、音频素材，建立项目素材库。
- 使用 ffmpeg 提取视频时长、分辨率和关键帧缩略图。
- 根据文稿生成 storyboard 分镜表。
- 手动编辑分镜，包括旁白、画面建议、素材需求、花字、动效、节奏和时长。
- 根据分镜、素材、SRT 字幕和旁白音频生成 timeline。
- 配置 AI API 后，可用真实 AI 辅助理解文稿和识别素材。
- 尝试通过 pyJianYingDraft 生成剪映草稿文件夹。

## 使用流程

1. 启动本地网页。
2. 创建新项目。
3. 上传文稿。
4. 上传 SRT 字幕，可选但推荐。
5. 生成 storyboard 分镜表。
6. 检查并修改分镜。
7. 上传视频、图片、旁白录音和音乐素材。
8. 生成 timeline。
9. 检查素材匹配和轨道安排。
10. 生成剪映草稿。
11. 打开剪映，在草稿列表中继续人工精修和导出。

## 推荐准备的素材

- 文稿：`.txt`、`.md`、`.docx`
- 字幕：`.srt`
- 旁白录音：`.mp3`、`.wav`
- 视频素材：`.mp4`、`.mov`
- 图片素材：`.png`、`.jpg`、`.webp`
- 音乐或音效：`.mp3`、`.wav`

有完整旁白录音和 SRT 字幕时，timeline 时间轴会更准确。

## 视频风格模板

内置 4 种风格模板：

- 社科解释型：逻辑清晰，适合论文截图、新闻截图、数据图表。
- 情绪共鸣型：节奏稍慢，适合生活化 B-roll 和慢推画面。
- B站知识型：节奏更快，花字更多，画面变化更频繁。
- 小红书口播型：字幕更大，信息点明确，适合竖屏表达。

## 本地运行

### Windows

第一次使用：

```text
双击 install_windows.bat
```

之后启动：

```text
双击 start_windows.bat
```

浏览器会打开：

```text
http://localhost:8000
```

### macOS

第一次使用：

```bash
chmod +x check_environment_mac.sh install_mac.sh start_mac.sh
./install_mac.sh
```

之后启动：

```bash
./start_mac.sh
```

## 环境要求

- Python 3.11+
- ffmpeg / ffprobe，推荐安装，用于识别素材时长、分辨率和缩略图
- 剪映或 CapCut，可选，用于打开生成的草稿
- Node.js 20+，仅在需要重新构建前端时使用

如果使用 Windows 便携版，通常不需要单独安装 Python。

## AI API 配置

进入页面中的 `本地设置`，可以配置 OpenAI-compatible API：

- API Base URL
- API Key
- 文本模型名称
- 视觉模型名称

文本模型用于理解文稿、生成分镜和处理修改要求。视觉模型用于识别素材缩略图和关键帧。

如果不配置 AI，系统会使用本地 mock 逻辑，仍可生成基础 storyboard 和 timeline，但理解能力有限。

## 剪映草稿配置

如果要直接生成剪映可识别的草稿，需要在 `本地设置` 中配置剪映草稿目录。

Windows 常见路径类似：

```text
C:\Users\你的用户名\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft
```

如果找不到路径，可以先打开剪映，新建一个空草稿，再回到本工具中扫描候选路径。

生成成功后，不需要把 ZIP 导入剪映。直接打开剪映，在本地草稿列表中找同名草稿。

## 当前限制

- 当前生成的是粗剪草稿，不是最终成片。
- 不自动操作剪映鼠标，不自动导出视频。
- 剪映草稿生成依赖 pyJianYingDraft，不同剪映版本可能存在兼容差异。
- macOS 上的剪映/CapCut 草稿兼容性需要按实际机器测试。
- 素材太少时，timeline 可能会重复使用同一段素材。
- 没有 ffmpeg 时，素材仍可上传，但视频分析能力会受限。
- AI 生成质量取决于所配置模型和提示要求。

## 建议使用方式

先让工具完成：

```text
文稿拆段 -> 分镜表 -> 素材匹配 -> timeline -> 剪映草稿
```

然后在剪映中完成：

```text
节奏精修 -> 字幕修正 -> 画面调整 -> 包装增强 -> 导出成片
```

这个项目适合把重复、机械的粗剪准备工作前置完成，让人工剪辑把精力放在审美判断和最终表达上。
